# Changelog

## 0.1.0 - 2026-09-22

- Initial public release.
- Git-base and branch-history authority for committed debt ledgers.
- JSON and JSONL scanner protocol with stable finding IDs.
- Independent repair checks with explicit evidence.
- Explicit `init`, `check`, and `accept` workflow.
- Worktree and staged-index evaluation.
- Race-safe config and ledger writes pinned to verified repository directories.
- Runnable example with a deterministic runtime repair postcondition.
